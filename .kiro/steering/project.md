# Gloam Hollow — Project Steering

- Project: Gloam Hollow: A Lantern Walk (Monsoon Marquee), a browser exploration game built with Kiro for Kiroween 2026, Frankenstein category.
- Tone: spooky and gentle. The scares are atmosphere, never jumpscares. Ghosts are warm, not gory.
- Art: layered SVG shapes, bold outlines, coloring-book flat fills. Palette: ink black, bone white, lantern amber. No image files.
- Audio: WebAudio-synthesized only (wind, bell, lantern hiss, wisp chimes). No audio files.
- Tech: plain HTML, CSS, and JavaScript. No third-party assets, no frameworks.
- Core loop: explore by lantern light, find ember-wisps, carry up to two at a time, return them to the town well before the seventh bell.
